# Calorie Tracker App

## Project Overview

A comprehensive daily nutrition tracking application built with HTML, CSS, and plain JavaScript. This application allows users to log their food intake, monitor calorie consumption, track macronutrients, and set daily fitness goals. The interface is designed to be visually appealing and highly intuitive, providing real-time feedback on progress.

## Features

### 🔐 **Personalized Goals & Settings**
- Users can set custom daily goals for Calories, Protein, Carbs, and Fat.
- The app calculates and displays recommended daily values based on general fitness guidelines.
- Goals are persistent and stored in the browser's `localStorage`.

### 🍎 **Food Logging System**
- A modal interface for easily adding new food items.
- Input fields for Meal Type (Breakfast, Lunch, Dinner, Snacks).
- Calories and Macronutrient breakdown (Protein, Carbs, Fat).
- **Smart Food Suggestions**: As the user types, the app suggests foods based on common items (e.g., "chicken", "rice", "apple") to speed up logging.

### 📊 **Real-time Dashboard**
- **Calorie Tracker**: Visual progress rings and bar graphs showing consumed vs. remaining calories.
- **Macronutrient Breakdown**: Dedicated cards for Protein, Carbs, and Fat with individual progress meters.
- **Food Diary**: A chronological list of all logged foods with edit and delete functionality.

### 🧭 **Navigation & Calendar**
- **Date Navigation**: Navigate between days to view past or future entries.
- **Today Button**: Quick reset to the current date.
- **Responsive Design**: Seamless transition between desktop and mobile views.
